# Experimental Methodology

Every recorded dataset should be accompanied by enough information to repeat
the experiment:

- Date, location and operator.
- Repository commit identifiers.
- Map and trajectory identifiers.
- Sensor warm-up time and active channels.
- Sensor mounting geometry.
- Environmental conditions and ventilation state.
- Source material, position and exposure timing.
- Logging and mapping parameters.
- Deviations or observed failures.

Generated measurements belong outside Git by default. Curated examples may be
added under `examples/measurements/` with a short description and no sensitive
location or participant information.
